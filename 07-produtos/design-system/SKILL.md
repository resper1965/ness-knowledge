## Scope boundary

This skill applies only to authenticated product interfaces. Before applying dark theme, zero radius, image restrictions or a fixed shell, confirm the artifact is an operational application. Institutional websites and materials follow the Brandbook and the Website Creative Direction.

Read the README.md file within this skill, and explore the other available files.
For product mocks and prototypes, copy assets out and create static HTML files for the user to view. If working on production product code, use the assets and rules as the interface authority.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

Non-negotiables for this brand: single accent (BlueDot #00ADE8, and the dot in a product mark never takes the text colour); product names lowercase with an internal dot (n.iso); `ness.` appears only on authentication and in the account menu, never in the working area; no vendor names in the interface; radius 0, no gradients, no backdrop-filter; Lucide icons at stroke 1.5; small text must clear 4.5:1 contrast; every data screen ships empty, loading (skeleton), error and no-permission states.
