# UI kit — n.iso

Telas completas do produto, aplicando o sistema. Servem como ponto de partida: duplique e troque o domínio.

| Arquivo | O que é |
| --- | --- |
| `Shell.dc.html` | Shell parametrizado da família — marca, tenant, navegação, conta, banda de título, recolhimento. **Comece por aqui num produto novo.** |
| `Prototipo SoA.dc.html` | Tela de trabalho hi-fi: lista com facetas, seleção em lote com desfazer, drawer de detalhe, gate de justificativa, trilha de auditoria, todos os estados. |
| `Prototipo Autenticacao.dc.html` | Fluxo de entrada completo — **sem domínio, reutilizável tal e qual** em qualquer produto da família. |
| `Wireframes GRC.dc.html` | Kit lo-fi com ~35 telas em 8 turnos. O cartão **6a** é o registro de decisões vigentes. |

Abra direto no navegador. Os dois protótipos são interativos: percorra com mouse e teclado — parte das decisões só aparece em interação (desfazer, escalonamento do desafio anti-abuso, travas de justificativa, cascata do `Esc`).
